# Fixtures

Fictional data only. Nothing here is a real balance, paycheck, debt or score.

The tracker's sample data is not stored as files; it is generated by
`apps-script/SampleData.gs` relative to the build date so the Dashboard's
current-month and current-week sections always have something to show. Every
generated row carries `SAMPLE` in its Notes (Transactions also `Created By =
sample-data`), and Finance Tracker → Clear sample data… removes exactly those
rows.

The Node tests (`tests/run-tests.js`) run that generator inside the mocked
sheet, so the same fictional dataset is what gets checked here and what the
owner sees after the first build.

If a bug needs a specific scenario, add it to `sampleDataset_()` with a
`SAMPLE — …` note rather than adding a data file here.
